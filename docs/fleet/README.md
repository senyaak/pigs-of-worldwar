# The agent fleet — index

Autonomous Claude sessions that read the original and build the remake from it
through GitHub issues and pull requests. The owner plays what they build and
answers what only play can answer.

The roles and the process are shared with the owner's other fleets: a pinned
version of `senyaak/claude-fleet`, copied into `.claude/` and never edited
here. What is this project's own is in this folder.
