# History — index

What happened, as opposed to what is true now ([../facts/](../facts/)) and
what is still to do ([../todo.md](../todo.md)). Open the subsystem a task lands
in when the reason behind a number matters.

**The files below are frozen as of 2026-11-02.** Each grew by appending to its
end, and two changes that both append to one file conflict every time. A new
record is a new file in the subsystem's folder, named
`<subsystem>/YYYY-MM-DD-<slug>.md`, and its line goes into the list below it.
Most work needs no record at all: the PR that did it says what happened.

- [frontend.md](frontend.md) — the menu's machine: what moves on it, what it sounds like, how a screen arrives and leaves
- [pig.md](pig.md) — the battle model, a landing on a wall, the draw scale, the footsteps
- [status.md](status.md) — where the remake stood, the lists play gave, what was not read
- [training.md](training.md) — CAMP's script, where it can be put, and the dummy that ends the mission
- [turns.md](turns.md) — the clock and the beats around it, what ends a turn, how input is polled, the AI's sessions
- [view.md](view.md) — the chase camera, the fades, the thrown weapon's own view, the judder measure
- [weapons.md](weapons.md) — the shot and its sights, the grenade passes, the mines, the charges, the blast, the bazooka
- [why.md](why.md) — the reasoning behind the numbers the engine is built on
- [world.md](world.md) — water and bridges, the buildings and the way in, the props, everything breakable
- [worklist/](worklist/README.md) — the old work list's closed entries, one file each
